# Bases de Datos · DAM 25/26

Apuntes, ejercicios y exámenes de práctica de la asignatura **Bases de Datos** de 1.º de Desarrollo de Aplicaciones Multiplataforma (DAM), curso 2025/2026.

## De qué trata la asignatura

Bases de Datos enseña a guardar la información de una aplicación de forma ordenada y fiable: cómo se diseña un modelo de datos a partir de un diagrama entidad-relación, cómo se crea en un sistema relacional, cómo se consulta y modifica con **SQL**, cómo se programa dentro de la propia base de datos y qué alternativas existen fuera del modelo relacional.
